# ربات هوشمند تغییر قیمت لیست

لیست قیمت را (PDF یا عکس) به ربات تلگرام بده و بگو «۱۰ درصد افزایش». ربات قیمت‌ها را پیدا می‌کند، قیمت جدید را حساب می‌کند و می‌پرسد **خروجی را با چه فرمتی می‌خواهی: PDF، Excel یا عکس**. خروجی همان لیست با همان ظاهر است و فقط قیمت‌هایش عوض شده.

## چه کار می‌کند

| ورودی | روش |
|---|---|
| PDF متنی (خروجی Word / Excel / Numbers) | قیمت‌ها از خود متن PDF خوانده و با **همان فونت داخل PDF** بازنویسی می‌شوند. پس‌زمینه، خطوط جدول و بقیه صفحه دست نمی‌خورد. |
| عکس، اسکن، PDF تصویری | هوش مصنوعی قیمت‌ها را پیدا می‌کند. هر عدد تا پیکسل دقیق روی جدول قفل می‌شود. عدد قدیمی پاک و پس‌زمینه بازسازی می‌شود. عدد جدید با نزدیک‌ترین فونت، هم‌اندازه، هم‌رنگ و هم‌راستای اصلی نوشته می‌شود. |

**دو هوش مصنوعی با هم (Claude و OpenAI):** وقتی هر دو کلید تنظیم باشد، هر صفحه را هر دو مدل مستقل بررسی می‌کنند و نتیجه‌ها با هم ادغام می‌شود:
- قیمتی که هر دو قبول دارند پذیرفته می‌شود.
- اگر فقط یکی عددی را قیمت بداند، فقط وقتی پذیرفته می‌شود که در ستون قیمت باشد و شکل قیمت داشته باشد. کد کالا، سال و تعداد خودبه‌خود حذف می‌شوند.
- در عکس‌ها اگر دو مدل عدد را متفاوت بخوانند، آن عدد جداگانه و بزرگ‌شده دوباره خوانده می‌شود و رأی اکثریت ملاک است.
- اگر هم خوانا نباشد، **تغییر داده نمی‌شود** و به کاربر هشدار داده می‌شود. عدد اشتباه هیچ‌وقت نوشته نمی‌شود.
- اگر یکی از سرویس‌ها قطع یا خطادار باشد، دیگری به‌طور خودکار کار را ادامه می‌دهد.

با فقط یک کلید هم کار می‌کند. در آن حالت همان مدل برای عددهای عکس، خواندن دوم مستقل را انجام می‌دهد.

**دستورهای هوشمند:**
- ۱۰ درصد افزایش
- ۵٪ کاهش
- ۱۵ درصد افزایش و رند به هزار
- فقط پرایدها ۲۰ درصد، بقیه ۱۰ درصد
- ردیف ۱ تا ۱۰ رو ۵۰۰ هزار تومن اضافه کن (تبدیل تومان/ریال خودکار)
- قیمت ردیف ۵ رو بکن ۷۰ میلیون

**خروجی‌ها:**
- **PDF:** همان فایل با قیمت‌های جدید. اگر ورودی عکس باشد، عکس ویرایش‌شده در یک PDF.
- **Excel:** جدول کامل لیست، ستون به ستون و راست‌به‌چپ. قیمت‌ها به صورت عدد واقعی با جداکننده هزارگان هستند و یک برگه «تغییرات» هم دارد با قیمت قبلی، جدید و درصد تغییر هر ردیف.
- **عکس:** اگر ورودی عکس باشد، همان عکس با همان فرمت. اگر PDF باشد، هر صفحه یک عکس با کیفیت ۲۰۰ DPI.
- **همه:** هر سه با هم.

## راه‌اندازی روی Railway
1. این پوشه را در یک ریپوی GitHub (خصوصی) بگذار و در Railway از روی آن پروژه بساز. Dockerfile و `railway.json` خودکار شناخته می‌شوند.
2. در بخش **Variables** این‌ها را تنظیم کن:
   - `TELEGRAM_BOT_TOKEN`: از BotFather
   - `ANTHROPIC_API_KEY`: از console.anthropic.com
   - `OPENAI_API_KEY`: از platform.openai.com
   - `ALLOWED_USER_IDS`: شناسه عددی خودت (در ربات `/id` بزن). بدون این، هر کسی می‌تواند از اعتبار API تو استفاده کند.
3. نیازی به پورت یا دامنه نیست؛ ربات با polling کار می‌کند. فقط **یک** نمونه (replica) اجرا کن.

بقیه تنظیمات اختیاری در `.env.example` توضیح داده شده‌اند: مدل‌ها، اولویت، سطح دقت، رأی‌گیری، و `OPENAI_BASE_URL` برای درگاه‌های سازگار با OpenAI.

## اجرای محلی
```
pip install -r requirements.txt
cp .env.example .env   # و مقادیر را پر کن
python bot.py
```

## دستورهای ربات
- `/start` یا `/help`: راهنما
- `/status`: هوش مصنوعی فعال و فایل‌های جلسه
- `/reset`: شروع دوباره
- `/id`: شناسه عددی شما

## فونت‌ها (برای عکس‌ها مهم است)
- **PDF متنی:** فونت از خود فایل برداشته می‌شود و نیازی به کاری نیست.
- **عکس:** اگر لیست‌هایت با فونت‌هایی مثل B Nazanin، B Homa، B Titr، B Yekan یا IRANSans تایپ شده‌اند، فایل TTF آن‌ها را در پوشه `fonts/` بگذار تا عددهای جدید دقیقاً هم‌شکل اصلی شوند. ربات خودش مشابه‌ترین فونت را انتخاب می‌کند.

## نکته‌ها
- عکس را به صورت «فایل» بفرست تا تلگرام کیفیتش را کم نکند.
- هر دستور روی فایل اصلی اعمال می‌شود، نه روی خروجی قبلی.
- بعد از هر خروجی می‌توانی فرمت دیگری هم بگیری یا دستور تازه بدهی.
- بدون هیچ کلید هوش مصنوعی فقط PDFهای متنی کار می‌کنند، با تشخیص ساده: عددهای سه‌رقم‌سه‌رقم جدا شده در ستون قیمت.

## ساختار کد

| `bot.py` | ربات تلگرام: جلسه‌ها، دکمه‌ها، انتخاب فرمت خروجی |
| `pricebot/pipeline.py` | تشخیص قیمت‌ها و ادغام پاسخ دو مدل (رأی‌گیری) |
| `pricebot/ai.py` | Claude و OpenAI: خروجی ساختاریافته، جایگزینی خودکار هنگام خطا |
| `pricebot/pdftext.py` | استخراج و جایگزینی دقیق عدد در لایه متنی PDF |
| `pricebot/raster.py`، `pricebot/fonts.py` | پیدا کردن پیکسلی، پاک کردن، تشخیص فونت و نوشتن عدد روی عکس |
| `pricebot/outputs.py`، `pricebot/excel.py` | ساخت خروجی PDF، عکس و Excel |
| `pricebot/commands.py`، `pricebot/numfmt.py` | فهم دستور، محاسبه، رند و قالب‌بندی عدد (فارسی/لاتین، `,` و `/`) |
